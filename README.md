# Inventory Scanner

A QR-code inventory scanner for Param Anand PLLC. Scan an item's label,
enter the quantity needed, and it's logged straight to a connected
Google Sheet.

## Setup
1. Open this site (once published via GitHub Pages) in Safari/Chrome on your phone.
2. Tap the gear icon → paste your Google Apps Script Web App URL → Save.
3. Tap "Start camera" and scan a label.

See the companion `InventoryScannerWebApp.gs.txt` and QR label sheet
shared separately for the rest of the setup.
